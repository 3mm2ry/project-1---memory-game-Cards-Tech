# Technologies  Memory Match

## Technologies Used

- HTML
- CSS
- JavaScript

## Description

Tech Pair Challenge is a memory game using technology logos such as HTML, CSS, JavaScript, Git, and GitHub.

The player selects two cards and tries to find matching technology pairs.

The player must match all cards before the 60-second timer ends.

## User Stories

- As a user, I want to reveal technology cards.
- As a user, I want to match the same logos.
- As a user, I want to see the remaining time.
- As a user, I want to see a win or lose message.
- As a user, I want to play again.
